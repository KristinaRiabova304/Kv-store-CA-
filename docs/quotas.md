# Квоти сервісів, які можуть заважати в Milestone 2

Звідки значення: `docs/evidence/quotas.txt`, його створив `scripts/check-quotas.sh` 2026-11-01
в регіоні `us-east-1`. Обмеження регіонів і типів серверів - з `docs/labrole.md`.

| Квота | Моє значення | Скільки треба для M2 | Ризик |
|---|---|---|---|
| Running On-Demand Standard A, C, D, H, I, M, R, T, Z instances, у **vCPU** | **256** vCPU | 3 × t3.micro = 6 vCPU, плюс клієнт YCSB | Низький: квота велика |
| Дозволені типи серверів | `t3.micro` можна, `m5.4xlarge` заборонено явним Deny | лише малі типи | **Високий**: сильніший сервер для бенчмарку взяти не вийде, точну межу я не знаю |
| Дозволені регіони | лише `us-east-1` і `us-west-2`, решту блокує SCP | 1 регіон | Низький для M2. Заважатиме, лише якщо захочу реплікацію між регіонами |
| VPCs per Region | **5**, зараз зайнято **2** | ще 1 | Середній: лишається 3 вільних, тож зайві VPC з лаб треба прибирати |
| Subnets per VPC | 200 | 4 | Низький |
| Internet gateways per Region | 5 | 1 | Низький |
| NAT gateways per AZ | 5 | 0-1 | Низький, ціна важливіша за квоту |
| Inbound or outbound rules per security group | 60 | 1-2 правила в кожній групі | Низький |
| Application Load Balancers per Region | 50 | 0-1 | Низький |
| Lambda concurrent executions | **400** | лише якщо шарди будуть на Lambda | Середній: на 400 одночасних викликах YCSB з великою кількістю потоків може впертися в ліміт |
| DynamoDB tables per Region | 2500 | лише якщо використаю як бекенд | Низький |
| EC2-VPC Elastic IPs | не прочиталося, `TooManyRequestsException`; зараз використано 0 | 0-1 | Низький, типове значення 5 |
| CloudFormation stacks | не прочиталося, `TooManyRequestsException` | 2-4 | Низький, типове значення 2000 |
| Тривалість сесії лаби | приблизно 4 год | довгі прогони YCSB | Середній: бенчмарки треба вміщати в одну сесію |

## Висновки
- Квота vCPU **не** обмежує: 256 vCPU вистачить із великим запасом.
- Реально заважати можуть **обмеження sandbox**, а не квоти AWS: лише малі типи серверів
  і лише два регіони. Їх не видно в Service Quotas, я знайшла їх через `AccessDenied`.
- **VPC**: з п'яти можливих уже зайнято два. Треба стежити, щоб лаби курсу не забрали решту.
- У sandbox не можна попросити збільшити квоту, тому дизайн має вкладатися в ці значення.
- Сам Service Quotas має ліміт на кількість запитів: два виклики впали з `TooManyRequestsException`.
